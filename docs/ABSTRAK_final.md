## ABSTRAK (Bahasa Indonesia)

**SIREKON: PENGEMBANGAN MODUL UNTUK KLASIFIKASI TEKS BERITA TRANSAKSI TRANSFER PADA SISTEM REKONSILIASI KEUANGAN**

Proses rekonsiliasi keuangan berperan penting dalam menjaga konsistensi laporan kas perusahaan. Namun, perusahaan mitra (*software house*) masih menghadapi kendala pencocokan mutasi rekening koran lintas bank secara manual yang tidak efisien dan rentan terhadap *human error*. Teks keterangan transaksi perbankan umumnya bersifat pendek, tidak terstruktur, minim konteks, dan memuat banyak singkatan tidak baku, sehingga pendekatan *rule-based* konvensional tidak adaptif. Penelitian ini mengembangkan modul *Natural Language Processing* (NLP) sebagai bagian dari sistem rekonsiliasi keuangan cerdas SIREKON (Pool 2). Modul ini mengombinasikan tahapan *text preprocessing* (normalisasi, tokenisasi, kamus sinonim perbankan, dan *stopword removal*), ekstraksi fitur gabungan TF-IDF *word n-gram* (1–2) serta *character n-gram* (3–5), dan algoritme *Support Vector Machine* (SVM) terkalibrasi untuk memetakan transaksi ke dalam sub-kategori *Chart of Accounts* (CoA) pada arus *cash in* (kredit) dan *cash out* (debit). Untuk menangani transaksi ambigu, diterapkan mekanisme *confidence threshold* yang mengalihkan prediksi berkepercayaan rendah ke modul *Knowledge Base* (Pool 3) guna divalidasi menggunakan aturan *forward chaining* berbasis data ERP. Hasil pengujian *5-fold Stratified Cross-Validation* pada data transaksi riil menunjukkan bahwa kombinasi TF-IDF dan SVM Linear mencapai akurasi **95,5%** dan **Macro-F1 0,895**, mengungguli *Random Forest* (Macro-F1 0,776), SBERT (0,780), dan FinBERT (0,771; signifikan secara statistik dengan $p = 0,0168$). Pada nilai ambang optimal **$\tau^* = 0,72$**, modul NLP mengklasifikasikan **82,80%** transaksi secara otomatis dengan tingkat akurasi **99,57%** serta menyaring **93,3%** kesalahan prediksi ke Pool 3. Integrasi hibrida antara Pool 2 dan Pool 3 menghasilkan *Overall System Coverage* sebesar **94,62%** dengan akurasi gabungan **98,11%**, sehingga hanya menyisakan **5,38%** transaksi yang memerlukan konfirmasi manual staf keuangan.

**Kata kunci:** Rekonsiliasi Keuangan, *Natural Language Processing*, *Support Vector Machine*, TF-IDF, *Confidence Threshold*, *Knowledge Base*.

## ABSTRACT (English)

**SIREKON: MODULE DEVELOPMENT FOR TEXT CLASSIFICATION OF TRANSFER TRANSACTION NARRATIONS IN FINANCIAL RECONCILIATION SYSTEMS**

The financial reconciliation process plays a vital role in maintaining consistent corporate cash statements. However, the partner software house faces operational challenges with manual, inefficient, and error-prone matching of heterogeneous bank statements. Banking transaction narrations are typically short, unstructured, lack context, and contain non-standard abbreviations, rendering conventional rule-based approaches non-adaptive. This study develops a Natural Language Processing (NLP) module within the intelligent financial reconciliation system SIREKON (Pool 2). The module combines text preprocessing (normalization, tokenization, banking synonym dictionary, and stopword removal), hybrid TF-IDF feature extraction using word n-grams (1–2) and character n-grams (3–5), and a calibrated Support Vector Machine (SVM) classifier to map transaction narrations into Chart of Accounts (CoA) sub-categories across cash in (credit) and cash out (debit) flows. To handle ambiguous transactions, a confidence threshold mechanism routes low-confidence predictions to the Knowledge Base module (Pool 3) for cross-validation using ERP-based forward chaining rules. Evaluation using 5-fold Stratified Cross-Validation on real transaction data demonstrates that the TF-IDF and Linear SVM combination achieves **95.5%** accuracy and a **Macro-F1 score of 0.895**, outperforming Random Forest (Macro-F1 0.776), SBERT (0.780), and FinBERT (0.771; statistically significant at $p = 0.0168$). At the optimal threshold of **$\tau^* = 0.72$**, the NLP module automatically classifies **82.80%** of transactions with **99.57%** accuracy while successfully filtering **93.3%** of misclassifications to Pool 3. The hybrid integration of Pool 2 and Pool 3 achieves an **Overall System Coverage of 94.62%** with a combined accuracy of **98.11%**, leaving only **5.38%** of transactions requiring manual review by finance staff.

**Keywords:** Financial Reconciliation, Natural Language Processing, Support Vector Machine, TF-IDF, Confidence Threshold, Knowledge Base.
